# SCRFD kernel measurements — 2026-09-10

Radeon 8060S (`gfx1151`), HRX 0.4.0 and its pinned compiler. Compared with
commit `c3e6249`, using the same lossless face fixture, batch 1 and
`max_batch=16`. Three paired runs reverse executable order each round;
each uses 10 warmups and 300 samples. Values below are medians of run medians.

| Scope | Before, ms | After, ms | Reduction |
| --- | ---: | ---: | ---: |
| Resident graph forward | 2.241 | 2.133 | 4.8% |
| End-to-end inference | 2.725 | 2.644 | 3.0% |

End-to-end includes resizing, host I/O and detection decoding. Image decoding,
model loading and compilation are excluded. Both scopes use synchronized host
clocks, not GPU timestamps. These local results do not establish throughput
for larger batches. [Raw results](kernels-2026-09-10.json) include every median,
p95, direct-dispatch measurement and executable digest.

```bash
cargo build --release --locked
HRX_OFFLINE=1 HF_HUB_OFFLINE=1 target/release/scrfd-hrx \
  --input tests/fixtures/t1.png --max-batch 16 --benchmark 300
```

The first two convolutions have 28 output channels. Their new implicit-GEMM
kernel computes 32 channels with four waves, rather than 64 with eight.
It retains FP16 operands, FP32 accumulation, prefetched gathers and fused
bias/ReLU. Staging and epilogue share 7,680 bytes of LDS. Output storage stays
64 channels wide, with its upper half explicitly zeroed for safe buffer reuse.
Other convolutions retain their existing kernels.

Preprocessing now accepts RGB and writes each normalized, eight-channel FP16
pixel with one vector store. The CLI passes decoded RGB directly. The baseline
swapped those same pixels to BGR before inference, so both runs represent the
same image. SCRFD still normalizes by 128; ArcFace still normalizes by 127.5.

The comparison used krea2's spatial/channel tile variants and h3's staging
reuse as references. Wider spatial tiles, general staging reuse and additional
epilogue unrolling did not improve full-model execution here. A 32-channel
head variant added no measurable benefit and was omitted.

Full numerical reference, face fixture and changing-batch tests pass with
unchanged tolerances. A separate GPU test checks RGB channel order and all
five padding channels after overwriting the destination with nonzero bytes.
